# Limites et verification

Le projet annonce des versions auditees, sans etendre cette assurance a toute configuration personnalisee.
Le MockProver ne suffit pas a prouver l absence de sous-contrainte avec des temoins adverses.
Les parametres de limbs, tables de range et tailles de vecteurs sont des invariants de securite.
Les changements de backend Halo2 ou de feature GPU doivent etre suivis par version exacte.
Ce parcours repose sur halo2-base, halo2-ecc, les avis de securite et les notes de version.
Aucune installation, compilation, generation de preuve ou execution nouvelle n a ete effectuee.
Aucun benchmark n est revendique comme mesure ici.
Pour verifier, consulter les tests filtres et les audits publies dans le depot.
