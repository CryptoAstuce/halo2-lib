# Limites et vérification

Le projet annonce des versions auditées, sans étendre cette assurance à toute configuration personnalisée.
Le MockProver ne suffit pas à prouver l’absence de sous-contrainte avec des témoins adverses.
Les paramètres de limbs, tables de range et tailles de vecteurs sont des invariants de sécurité.
Les changements de backend Halo2 ou de feature GPU doivent être suivis par version exacte.
Ce parcours repose sur halo2-base, halo2-ecc, les avis de sécurité et les notes de version.
Aucune installation, compilation, génération de preuve ou exécution nouvelle n’a été effectuée.
Aucun benchmark n’est revendiqué comme mesuré ici.
Pour vérifier, consulter les tests filtrés et les audits publiés dans le dépôt.
